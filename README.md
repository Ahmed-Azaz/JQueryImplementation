# JQueryImplementation

A single-page website built with jQuery.

## The project

It's one page with four main sections — About, Gallery, Services, and a Complain form. Clicking any menu item shows that section and hides the rest, so the page stays clean and doesn't pile up multiple things at once.

### Services
A dropdown that opens and closes smoothly.

### Gallery
Browse through a set of images with prev/next arrows.

### Complain form
The part that took the most time. You enter your name, email, and message, hit send, and it shows you a preview of what you wrote before actually submitting. If you spot a mistake, you can go back to edit and try again.

## Tech stack

- HTML
- CSS
- jQuery 3.7.1

## Running it

Open `index.html` in your browser. No build tools, no dependencies to install.
